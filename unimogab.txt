请进入编程协作模式。本提示词末尾内嵌了完整 Python 程序。我只会另外上传两份 PDF，分别为任意 Unimog 项目的我方采购订单（Bestellung）和供应商订单确认（Auftragsbestätigung，AB）。不要要求我再次上传 Python 文件，不要仅凭文件名判断 PDF 类型。

收到两份 PDF 后，直接读取、识别、运行程序、人工复核并交付结果。无需询问我是否运行程序或是否生成文件。资料不足时必须写“未找到/无法确认”，不得猜测。

本提示词必须可重复用于未来不同年份、不同国家、不同客户、不同 Unimog 型号、不同数量和不同 Daimler Truck/Mercedes-Benz 文件版式。不得沿用上一次项目中的车型、数量、价格、Code、国家、城市、供应商 AB 号、订单号、日期或结论。所有事实必须从本次上传的两份 PDF 重新提取和验证。

## 四、配置 Code 完整核查

1. 提取 Bestellung 和 AB 中全部显式配置 Code。
2. 核对程序的全部 `OK`、`MISSING`、`REVIEW`、`IGNORED` 和 AB 中全部 `EXTRA`。
3. 同 Code 不等于同配置。即使程序标为 OK，也必须检查：
   - 描述；
   - 数量；
   - 规格；
   - 品牌；
   - 技术参数；
   - `ohne`；
   - `Entfall`；
   - `Serie`；
   - 否定词和限定词。
4. `MISSING` 必须区分：
   - AB 确实未记载；
   - 可能使用其他 Code；
   - OCR/提取失败；
   - 无法确认。
5. 疑似替代 Code、OCR 混淆或 J-Code 替代保持 REVIEW，除非 PDF 有明确等同依据。
6. `IGNORED` 和 `EXTRA` 必须评估是否改变车辆配置、价格、工艺或双方约定。
7. 必须检查无 Code 的正文是否与 EXTRA Code 可能相关，例如一方以自由文本记载防腐、轮胎、PTO、驾驶室或上装接口，另一方以 Code 表示。不得预设固定 Code，必须根据当次 PDF 判断是否等同。
8. 必须检查 Optional equipment，包括无 Code 或仅出现在价格附件中的选装项目。不得把报价选项自动当成已订购，也不得因 AB 未出现就直接认定供应商漏项。
9. 正文必须完整列出：
   - 所有 MISSING；
   - 所有 REVIEW；
   - 所有 IGNORED；
   - 所有 EXTRA；
   - 程序标 OK 但人工发现仍有差异的 Code。
10. 其余 OK Code 必须在报告附件或完整清单中逐项保留。

## 六、结论状态

人工结论只能使用以下状态：

- **明确矛盾**：双方对同一事项给出不能同时成立的内容；
- **需供应商确认**：存在缺失、变更、歧义、单车分配不明或承诺效力不明；
- **表述不同但可能兼容**：现有说法可能同时成立，但仍需解释；
- **未找到/无法确认**：检查后仍无法可靠定位或辨认。

保留程序原始状态，但不得以程序状态替代人工结论。没有充分证据时，不得宣称“订单完全一致”。

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
from __future__ import annotations

import argparse
import difflib
import json
import re
import sys
from dataclasses import asdict, dataclass
from pathlib import Path

try:
    import pdfplumber
except ImportError:
    raise SystemExit("缺少 pdfplumber，请运行: python -m pip install pdfplumber")

try:
    import pandas as pd
except ImportError:
    raise SystemExit("缺少 pandas/openpyxl，请运行: python -m pip install pandas openpyxl")

CODE_RE = re.compile(r"^[A-Z][A-Z0-9]{1,5}$")
STOP_CODES = {
    "MOTOR", "SEITE", "DATUM", "EUR", "UND", "MIT", "FUER", "VOM",
    "WERK", "HERR", "IHRE", "WIR", "LKW", "GMBH", "TYP", "MB",
    "PS", "NM", "MM", "AG", "SITZ", "ORDER", "DATE", "PRICE"
}

@dataclass
class CodeItem:
    code: str
    description: str
    page: int
    source: str
    optional_ohne: bool = False

@dataclass
class CodeCheck:
    code: str
    bestellung_description: str
    bestellung_page: int
    status: str
    ab_code: str = ""
    ab_description: str = ""
    ab_page: int = 0
    similarity: float = 0.0
    note_zh: str = ""
    note_de: str = ""


def clean(text: str) -> str:
    return re.sub(r"\s+", " ", (text or "").replace("\xa0", " ").replace("­", "")).strip()


def normalize_code(code: str) -> str:
    return re.sub(r"[^A-Z0-9]", "", code.upper())


def normalize_description(text: str) -> str:
    value = clean(text).upper().replace("ß", "SS")
    value = value.replace("UE", "U").replace("OE", "O").replace("AE", "A")
    return re.sub(r"[^A-Z0-9 ]", "", value)


def similarity(left: str, right: str) -> float:
    return difflib.SequenceMatcher(
        None, normalize_description(left), normalize_description(right)
    ).ratio()


def page_lines(page) -> list[str]:
    words = page.extract_words(
        x_tolerance=2,
        y_tolerance=3,
        keep_blank_chars=False
    ) or []
    rows = []
    for word in sorted(words, key=lambda x: (x["top"], x["x0"])):
        center_y = (word["top"] + word["bottom"]) / 2
        row = next(
            (r for r in reversed(rows[-6:]) if abs(r["y"] - center_y) <= 3.2),
            None
        )
        if row is None:
            row = {"y": center_y, "words": []}
            rows.append(row)
        row["words"].append(word)
        row["y"] = sum(
            (item["top"] + item["bottom"]) / 2 for item in row["words"]
        ) / len(row["words"])
    return [
        clean(" ".join(item["text"] for item in sorted(row["words"], key=lambda x: x["x0"])))
        for row in rows
    ]


def extract_pdf(pdf_file: Path) -> tuple[list[str], list[list[str]], list[dict]]:
    page_texts = []
    page_rows = []
    quality = []
    with pdfplumber.open(str(pdf_file)) as pdf:
        for page_number, page in enumerate(pdf.pages, 1):
            rows = page_lines(page)
            text = "\n".join(rows)
            page_rows.append(rows)
            page_texts.append(text)
            quality.append({
                "page": page_number,
                "characters": len(clean(text)),
                "words": len(page.extract_words() or []),
                "images": len(page.images or []),
                "text_empty": not bool(clean(text)),
            })
    return page_texts, page_rows, quality


def identify_document(page_texts: list[str]) -> tuple[str, list[str]]:
    text = clean("\n".join(page_texts)).upper()
    reasons = []
    order_score = 0
    ab_score = 0

    for marker, score in [
        ("ORDER FOR BRAND-NEW VEHICLES", 4),
        ("ANNEX 1 TO THE PURCHASE ORDER", 3),
        ("THE BUYER ORDERS", 2),
        ("OBJECT OF SALE", 1),
    ]:
        if marker in text:
            order_score += score
            reasons.append(f"Bestellung marker: {marker}")

    for marker, score in [
        ("ORDER-CONFIRMATION", 4),
        ("AUFTRAGSBESTÄTIGUNG", 4),
        ("WE CONFIRM", 3),
        ("YOUR ORDER", 1),
        ("TOTAL PRICE", 1),
    ]:
        if marker in text:
            ab_score += score
            reasons.append(f"AB marker: {marker}")

    if order_score >= 4 and order_score > ab_score:
        return "Bestellung", reasons
    if ab_score >= 4 and ab_score > order_score:
        return "AB", reasons
    return "Unclear", reasons


def probable_code(token: str) -> bool:
    token = normalize_code(token)
    if not CODE_RE.fullmatch(token) or token in STOP_CODES:
        return False
    return any(char.isdigit() for char in token) or len(token) <= 4


def extract_codes(page_rows: list[list[str]], source: str) -> dict[str, CodeItem]:
    found = {}
    for page_number, rows in enumerate(page_rows, 1):
        for raw_line in rows:
            line = clean(raw_line).lstrip("* ")
            if not line:
                continue
            matches = list(re.finditer(
                r"(?<![A-Z0-9])([A-Z][A-Z0-9]{1,5})\s+(?=[A-ZÄÖÜ0-9])",
                line,
                re.I
            ))
            valid = [match for match in matches if probable_code(match.group(1))]
            for index, match in enumerate(valid):
                code = normalize_code(match.group(1))
                end = valid[index + 1].start() if index + 1 < len(valid) else len(line)
                description = clean(line[match.end():end])
                if len(description) < 2:
                    continue
                if any(marker in description.upper() for marker in [
                    "REGISTERGERICHT", "IBAN", "UST-IDNR", "ALBERT-ZIEGLER-STR",
                    "DAIMLER TRUCK AG SITZ", "BOARD OF MANAGEMENT"
                ]):
                    continue
                item = CodeItem(
                    code=code,
                    description=description[:700],
                    page=page_number,
                    source=source,
                    optional_ohne=bool(re.match(r"^(OHNE|ENTFALL)\b", description, re.I)),
                )
                if code not in found or len(description) > len(found[code].description):
                    found[code] = item
    return found


def compare_codes(bestellung_codes, ab_codes):
    checks = []
    used_ab = set()

    for code, bestellung_item in bestellung_codes.items():
        if code in ab_codes:
            ab_item = ab_codes[code]
            used_ab.add(code)
            score = similarity(bestellung_item.description, ab_item.description)
            status = "OK" if score >= 0.45 else "REVIEW"
            checks.append(CodeCheck(
                code=code,
                bestellung_description=bestellung_item.description,
                bestellung_page=bestellung_item.page,
                status=status,
                ab_code=code,
                ab_description=ab_item.description,
                ab_page=ab_item.page,
                similarity=score,
                note_zh="同 Code，仍需人工检查品牌、数量、规格、否定词和技术参数。",
                note_de="Gleicher Code; Marke, Menge, Spezifikation, Negation und technische Parameter manuell prüfen.",
            ))
        elif bestellung_item.optional_ohne:
            checks.append(CodeCheck(
                code=code,
                bestellung_description=bestellung_item.description,
                bestellung_page=bestellung_item.page,
                status="IGNORED",
                note_zh="Bestellung 描述为 Ohne/Entfall，仍需确认是否影响实际配置。",
                note_de="Beschreibung enthält Ohne/Entfall; Auswirkung auf die reale Konfiguration prüfen.",
            ))
        else:
            checks.append(CodeCheck(
                code=code,
                bestellung_description=bestellung_item.description,
                bestellung_page=bestellung_item.page,
                status="MISSING",
                note_zh="Bestellung 中有此 Code，AB 中未按相同 Code 提取到。",
                note_de="Code in der Bestellung vorhanden, in der AB nicht unter demselben Code extrahiert.",
            ))

    extras = [
        item for code, item in ab_codes.items()
        if code not in used_ab and code not in bestellung_codes
    ]
    return checks, extras


def first_match(text: str, patterns: list[str]) -> str:
    for pattern in patterns:
        match = re.search(pattern, text, re.I | re.S)
        if match:
            return clean(match.group(1))
    return ""


def extract_fields(page_texts: list[str], source: str) -> dict[str, str]:
    text = "\n".join(page_texts)
    flat = clean(text)

    common = {
        "wheelbase": first_match(flat, [r"(?:WHEELBASE|RADSTAND)\s*:?[ ]*(\d+)\s*MM"]),
        "power_kw": first_match(flat, [
            r"ENGINE POWER\s*:?[ ]*(\d+)\s*KW",
            r"M1K\s+ENGINE.*?\b(\d+)\s*KW",
        ]),
        "baumuster": first_match(flat, [
            r"BAUMUSTER\s*:?[ ]*(\d{8})",
            r"MOD\.\s*(\d{8})",
            r"BM\s+(\d{8})",
        ]),
        "model": first_match(flat, [r"\b(U\s?\d{3,4})\b"]),
        "steering": first_match(flat, [
            r"STEERING TYPE\s*:?[ ]*([^\n]+)",
            r"Z01\s+(LEFT HAND DRIVE|RIGHT HAND DRIVE)",
        ]),
        "traffic_side": first_match(flat, [r"Z5Y\s+(VEHICLE,?\s+FOR\s+RIGHT-SIDE\s+TRAFFIC)"]),
        "currency": "EUR" if re.search(r"\bEUR\b", flat, re.I) else "",
    }

    if source == "Bestellung":
        common.update({
            "quantity": first_match(flat, [r"(\d+)\s*X\s+(?:MERCEDES-BENZ\s+)?UNIMOG"]),
            "order_date": first_match(flat, [
                r"ORDER\s+FOR\s+BRAND-NEW\s+VEHICLES\s+DATED\s+(\d{2}\.\d{2}\.\d{4})",
                r"DATED\s+(\d{2}\.\d{2}\.\d{4})",
            ]),
            "unit_price": first_match(flat, [
                r"PURCHASE PRICE PER UNIT.*?EUR\s*([\d.]+,\d{2})",
                r"PURCHASE PRICE.*?IS\s*([\d.]+,\d{2})",
            ]),
            "delivery": first_match(flat, [
                r"NON BINDING DELIVERY DATE FOR THE FIRST UNIT IS\s+(.+?)(?=NO LIABILITY|THE PURCHASE CONTRACT)",
            ]),
            "destination_country": first_match(flat, [
                r"COUNTRY OF DESTINATION.*?IS\s+([A-Z][A-Z ]+?)(?:\.|PAYMENT)",
            ]),
            "delivery_place": first_match(flat, [
                r"INCLUDING DELIVERY TO\s+([^,]+)",
            ]),
            "payment": first_match(flat, [
                r"TERMS OF PAYMENT:\s*(.+)$",
            ]),
            "purchase_order_number": first_match(flat, [r"\b(4500\d+)\b"]),
            "ab_number": "",
        })
    else:
        common.update({
            "quantity": first_match(flat, [r"YOUR ORDER:.*?\b(\d+)\s+MERCEDES(?:-BENZ)?\s+U\s?\d{3,4}"]),
            "order_date": first_match(flat, [r"YOUR ORDER:\s*DATED\s*(\d{2}\.\d{2}\.\d{4})"]),
            "unit_price": first_match(flat, [
                r"TOTAL PRICE(?:\s+[A-Z]{3}(?:\s+[A-Z0-9 -]+)?)?\s+EUR\s+([\d. ]+,\d{2})",
            ]).replace(" ", ""),
            "vehicle_price": first_match(flat, [r"VEHICLE PRICE\s+([\d ]+,\d{2})"]).replace(" ", ""),
            "transport": first_match(flat, [r"TRANSPORTATION CHARGES\s+([\d ]+,\d{2})"]).replace(" ", ""),
            "insurance": first_match(flat, [r"INSURANCE\s+([\d ]+,\d{2})"]).replace(" ", ""),
            "delivery": first_match(flat, [
                r"NON-BINDING DELIVERY DATE\s+(.+?)(?=TERMS OF PAYMENT)",
            ]),
            "delivery_place": first_match(flat, [
                r"TERMS OF DELIVERY:\s+(.+?)(?=$)",
            ]),
            "payment": first_match(flat, [
                r"TERMS OF PAYMENT:\s+(.+?)(?=TERMS OF DELIVERY)",
            ]),
            "purchase_order_number": first_match(flat, [r"\b(4500\d+)\b"]),
            "ab_number": first_match(flat, [
                r"([0-9 ]{9,14})\s+ORDER NO\.",
                r"ORDER NO\.\s*([0-9 ]{9,14})",
            ]),
        })
    return common


def normalized_number(value: str) -> str:
    return re.sub(r"[ .]", "", value or "")


def compare_fields(bestellung: dict, ab: dict) -> list[dict]:
    keys = sorted(set(bestellung) | set(ab))
    rows = []
    for key in keys:
        left = bestellung.get(key, "")
        right = ab.get(key, "")
        if key == "ab_number":
            status = "INFO"
        elif not left or not right:
            status = "REVIEW"
        elif normalized_number(left).casefold() == normalized_number(right).casefold():
            status = "OK"
        else:
            status = "REVIEW"
        rows.append({
            "key": key,
            "bestellung": left,
            "ab": right,
            "script_status": status,
            "manual_review_required": True,
        })
    return rows


def write_outputs(output_base: Path, payload: dict):
    output_base.with_suffix(".json").write_text(
        json.dumps(payload, ensure_ascii=False, indent=2),
        encoding="utf-8"
    )

    code_rows = []
    for item in payload["code_checks"]:
        code_rows.append({
            "Bestellung Code": item["code"],
            "Bestellung Description": item["bestellung_description"],
            "Bestellung Page": item["bestellung_page"],
            "Script Status": item["status"],
            "AB Code": item["ab_code"],
            "AB Description": item["ab_description"],
            "AB Page": item["ab_page"],
            "Similarity": item["similarity"],
            "说明": item["note_zh"],
            "Hinweis": item["note_de"],
        })

    for item in payload["extra_in_ab"]:
        code_rows.append({
            "Bestellung Code": "",
            "Bestellung Description": "",
            "Bestellung Page": "",
            "Script Status": "EXTRA",
            "AB Code": item["code"],
            "AB Description": item["description"],
            "AB Page": item["page"],
            "Similarity": "",
            "说明": "AB 新增 Code，必须人工判断配置、价格和工艺影响。",
            "Hinweis": "Zusätzlicher AB-Code; Auswirkung auf Konfiguration, Preis und Prozess manuell prüfen.",
        })

    xlsx = Path(str(output_base) + "_Codes.xlsx")
    with pd.ExcelWriter(xlsx, engine="openpyxl") as writer:
        pd.DataFrame(code_rows).to_excel(writer, index=False, sheet_name="Code Check")
        pd.DataFrame(payload["field_checks"]).to_excel(writer, index=False, sheet_name="Key Fields")
        pd.DataFrame(payload["bestellung_quality"]).to_excel(writer, index=False, sheet_name="Bestellung Pages")
        pd.DataFrame(payload["ab_quality"]).to_excel(writer, index=False, sheet_name="AB Pages")

        for sheet in writer.book.worksheets:
            sheet.freeze_panes = "A2"
            sheet.auto_filter.ref = sheet.dimensions
            for column in sheet.columns:
                width = min(max(len(str(cell.value or "")) for cell in column) + 2, 70)
                sheet.column_dimensions[column[0].column_letter].width = width


def main() -> int:
    parser = argparse.ArgumentParser(description="Universal Unimog Bestellung / AB checker")
    parser.add_argument("pdf1", type=Path)
    parser.add_argument("pdf2", type=Path)
    parser.add_argument("-o", "--output", type=Path, default=Path("Unimog_AB_Check_Result"))
    args = parser.parse_args()

    for file in (args.pdf1, args.pdf2):
        if not file.is_file():
            parser.error(f"文件不存在: {file}")

    pdf1_texts, pdf1_rows, pdf1_quality = extract_pdf(args.pdf1)
    pdf2_texts, pdf2_rows, pdf2_quality = extract_pdf(args.pdf2)

    pdf1_type, pdf1_reasons = identify_document(pdf1_texts)
    pdf2_type, pdf2_reasons = identify_document(pdf2_texts)

    if {pdf1_type, pdf2_type} != {"Bestellung", "AB"}:
        raise RuntimeError(
            "无法可靠识别两份 PDF 的类型。"
            f" PDF1={pdf1_type}, PDF2={pdf2_type}。"
            "不得强行交换输入，请人工检查标题和正文。"
        )

    if pdf1_type == "Bestellung":
        bestellung_file, ab_file = args.pdf1, args.pdf2
        bestellung_texts, ab_texts = pdf1_texts, pdf2_texts
        bestellung_rows, ab_rows = pdf1_rows, pdf2_rows
        bestellung_quality, ab_quality = pdf1_quality, pdf2_quality
    else:
        bestellung_file, ab_file = args.pdf2, args.pdf1
        bestellung_texts, ab_texts = pdf2_texts, pdf1_texts
        bestellung_rows, ab_rows = pdf2_rows, pdf1_rows
        bestellung_quality, ab_quality = pdf2_quality, pdf1_quality

    bestellung_codes = extract_codes(bestellung_rows, "Bestellung")
    ab_codes = extract_codes(ab_rows, "AB")
    code_checks, extras = compare_codes(bestellung_codes, ab_codes)

    bestellung_fields = extract_fields(bestellung_texts, "Bestellung")
    ab_fields = extract_fields(ab_texts, "AB")
    field_checks = compare_fields(bestellung_fields, ab_fields)

    counts = {
        status: sum(check.status == status for check in code_checks)
        for status in ("OK", "MISSING", "REVIEW", "IGNORED")
    }
    counts["EXTRA"] = len(extras)

    quantity_review = (
        bool(bestellung_fields.get("quantity"))
        and bool(ab_fields.get("quantity"))
        and bestellung_fields["quantity"] != ab_fields["quantity"]
    )

    payload = {
        "bestellung_file": str(bestellung_file),
        "ab_file": str(ab_file),
        "identification": {
            str(args.pdf1): {"type": pdf1_type, "reasons": pdf1_reasons},
            str(args.pdf2): {"type": pdf2_type, "reasons": pdf2_reasons},
        },
        "bestellung_quality": bestellung_quality,
        "ab_quality": ab_quality,
        "counts": counts,
        "quantity_review": quantity_review,
        "bestellung_fields": bestellung_fields,
        "ab_fields": ab_fields,
        "field_checks": field_checks,
        "code_checks": [asdict(item) for item in code_checks],
        "extra_in_ab": [asdict(item) for item in extras],
        "universal_scope": "不得复用历史项目的车型、数量、价格、Code、国家、地点或结论。",
        "warning_zh": (
            "程序输出仅为辅助证据。必须回到 PDF 原文人工复核数量、交期、品牌、"
            "轮胎、左右舵、Optional equipment、无 Code 正文及所有 EXTRA。"
        ),
        "warning_de": (
            "Die Programmausgabe ist nur ein Hilfsmittel. Menge, Liefertermin, Marke, Reifen, "
            "Lenkungsseite, optionale Ausstattung, Text ohne Code und alle EXTRA-Einträge "
            "müssen anhand der PDFs manuell geprüft werden."
        ),
    }

    write_outputs(args.output, payload)
    print(json.dumps(payload, ensure_ascii=False, indent=2))

    needs_review = (
        quantity_review
        or counts["MISSING"] > 0
        or counts["REVIEW"] > 0
        or counts["EXTRA"] > 0
        or any(row["script_status"] == "REVIEW" for row in field_checks)
    )
    return 2 if needs_review else 0


if __name__ == "__main__":
    sys.exit(main())
```

识别文件类型后运行，不得仅按照文件名顺序假定：

```bash
python unimog_ab_checker.py "第一份PDF.pdf" "第二份PDF.pdf" -o Unimog_AB_Check_Result
```

程序返回码 2 代表存在需要人工复核的事项，不等于程序执行失败。必须继续完成人工 PDF 复核和中德文报告。
